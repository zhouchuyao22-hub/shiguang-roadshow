◆ 痛点
所有 App 都在帮你「做更多」——
没有一个，在帮你「看见自己」。

😮‍💨 现代人说不出的空

?
"这一年好像什么都没干就过去了"

忙碌却记不住自己活过的证据。

?
"和爸妈、老朋友越来越远"

想联系，却总在"下次吧"里错过。

?
"想坚持，却总也坚持不下来"

没有反馈的努力，最容易放弃。

🧩 现有方案为什么都不行

✕
屏幕时间 / 记账 / 运动 App

单一切片、冰冷数据、负面评判——制造焦虑。

✕
年度 Wrapped（网易云/支付宝）

只有娱乐切片、一年一次、看完就结束、无行动。

✕
日记 / 打卡 / 习惯 App

要用户高频主动记录，坚持率极低——劝退 90%。

💡 机会缺口：一款「零操作 + 全景 + 温暖 + 有行动闭环 + 可分享」的产品——这个位置，市场上是空的。
◆ 核心洞察

三个反转，让人"啊？为什么没人做过"

拾光的灵魂不在功能，而在视角。同样的数据，换一个视角，就能从让人焦虑变成让人被爱。

反转 01

从「时间管理」
到「意义管理」

记录你花了多少时间 → 看见什么在滋养你

时间对每个人都一样，但什么在悄悄点亮你、什么在消耗你，从没人为你算过这笔账。

反转 02

从「揭露亏欠」
到「看见拥有」

照妖镜：你健身 0 次 → 聚光灯：你连续早睡 143 天

数据不变，视角决定它是让你焦虑，还是让你感到被爱。

反转 03

从「需要你记录」
到「我只负责看见」

又一个要打卡的 App → 你正常生活，它默默看见

零操作负担，是它能触达大众、而非只服务自律者的根本原因。

◆ 可落地性

非手机不可，别人抄不动

这正是它在「手机创新大赛」里最该被记住的价值。

🏰 天然壁垒：系统级数据 + 端侧 AI

拾光依赖的全是手机系统级数据——相册、健康、位置、屏幕时间、通话、日历。这些是普通第三方 App 拿不到、只有手机厂商 / 系统级 App 能深度调用的数据。再配合端侧大模型做归因与温暖叙事，构成别人短期抄不动的护城河，也是端侧 AI 能力最好的展示场景。

📷 端侧多模态识别

相册场景 / 人物 / 事件识别，技术成熟，全程本地。

🧠 端侧 LLM 归因

把冷数据酿成温暖洞察与因果解释，可调用手机端侧大模型。

⏱️ 本地时序聚合

频率 / 趋势 / 同比计算，轻量，无需云端。

🚀 MVP 一周可跑通

先做「成长 + 健康 + 感恩」三本账，数据最易得、情感最强、最好分享。

🔌 无需用户录入

不依赖任何未成熟技术，不需要平台开放数据，全是手机已有能力。

📈 渐进扩展

验证闭环后，逐步补全八本账本与 AI 成长教练。

🔒 隐私即信任：全部端侧处理，数据一步都不离开手机；一次授权可随时撤销；关系账本只统计通话频率/时长，绝不读取通话内容与短信正文；分享完全自愿。路演话术——"它比你自己更懂你的生活，但这些数据一步都不会离开你的手机。"
◆ 差异化 & 传播

不撞车，还自带裂变基因

竞品它做的拾光的不同
屏幕时间 App单讲时间、劝你少用全景 + 温暖，讲"热爱"而非"浪费"
记账 App单讲钱、花了多少讲"钱背后的价值观和心意"
运动 App（Keep/Strava）单讲运动数据把运动放进"成长+健康+归因"全景
相册（Google Photos）帮你找到那张照片帮你发现记忆与空白
Wrapped（网易云/支付宝）娱乐切片、一年一次全景 + 每周更新 + 行动闭环
日记 / 打卡 App需主动高频记录零操作、被动生成
同学的旅拍三作品旅行单场景覆盖"完整的人生"

每一条洞察，都是一句想发朋友圈的话

晒成长和热爱，不尴尬；不排名，只互相点亮。
